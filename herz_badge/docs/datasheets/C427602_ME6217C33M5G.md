## Notes for this board
- Use the SOT-23-5 column on p2. The application drawing on p1 numbers the pins like SOT-89-5 (1 CE, 4 VIN), which is wrong for M5. The AP2112K-3.3 symbol pinout (1 VIN, 2 GND, 3 EN, 5 VOUT) matches.
- The dropout curve is only given for the 5.0 V part. For the 3.3 V part only the 300 mA table value applies (100 typ / 180 max). Keep VSW ≥ ~3.5 V for Wi-Fi TX peaks (~340 mA).
- Iq vs V_IN (p7, C50 only) climbs to ~200 µA as V_IN approaches V_OUT. Expect higher Iq in dropout on a low battery; no 3.3 V curve is given.
- SOT-23-5 power dissipation is not given (only SOT-89-5 = 1000 mW). On USB, (4.6 - 3.3) V x 0.3 A ≈ 0.4 W at peaks.
- Tie CE to VIN (VSW); the datasheet forbids floating CE. V_OUT must not exceed V_IN + 0.3 V (reverse body diode, p5).
- Output may rise at loads ≤1 mA (p6), which matters in ESP32 deep sleep.
